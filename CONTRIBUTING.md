# Contributing to MİZAN-AI

Tesekkur ederiz! MİZAN-AI'ya katkida bulunmak istediginiz icin memnunuz.

## Davranis Kurallari

Lutfen projemize katkida bulunurken sunlara dikkat edin:

1. **Saygili olun** - Tum topluluk uyelerine karsi nazik ve saygili olun
2. **Geri bildirim yapici olun** - Eleştirilerinizi yapici ve faydali sekilde sunun
3. **Farkliliklari kabul edin** - Herkesi degerli ve saygili tutun

## Katkida Bulunma Süreci

### 1. Forklayin

Projeyi fork'layin: https://github.com/barancanercan/mizan-ai/fork

### 2. Branch Olusturun

```bash
git checkout -b feature/yeni-ozellik
```

### 3. Degisikliklerinizi Yapin

Kodunuzu yazin ve test edin.

### 4. Commit Yapin

```bash
git commit -m "feat: yeni ozellik eklendi"
```

### 5. Push Yapin

```bash
git push origin feature/yeni-ozellik
```

### 6. Pull Request Olusturun

GitHub uzerinden pull request olusturun.

## Kod Stili

- **Python**: PEP 8
- **Fonksiyonlar**: Acik ve anlasilir isimlendirme
- **Yorumlar**: Kodun ne yaptigini degil neden yaptigini aciklayin
- **Type Hints**: Mümkünse kullanin

## Test Gereksinimleri

- Yeni ozellikler icin test yazin
- Mevcut testlerin gectiginden emin olun
- Test coverage'i düsürmeyin

## Issue Bildirme

Hata veya ozellik talebi icin GitHub Issues kullanin:

1. **Bug Report**: "Bug" etiketi ile
2. **Feature Request**: "Enhancement" etiketi ile
3. **Soru**: "Question" etiketi ile

## Lisans

Katki yaparak, katkilarinizin MIT lisansi altında yayınlanacagini kabul etmissiniz.
